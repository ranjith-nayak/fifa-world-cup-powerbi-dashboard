# FIFA World Cup Analytics Dashboard

An interactive and visually engaging Power BI dashboard project focused on analyzing FIFA World Cup history and global football rankings.
This project combines historical tournament insights with modern FIFA ranking analytics using dynamic visual storytelling and data-driven exploration.

---

# Dashboard Overview

The project contains **two interactive dashboard pages**:

## 1. FIFA World Cup Analytics Dashboard

Focused on historical FIFA World Cup insights from 1930–2022.

### Key Insights:

* Total World Cup matches and goals
* Tournament attendance trends
* Most successful football nations
* Tournament expansion over time
* Host nation analysis
* Historical World Cup storytelling

---

## 2. FIFA Global Rankings Dashboard

Focused on modern FIFA rankings and football dominance analysis.

### Key Insights:

* Top nations by FIFA points
* Global football influence
* Confederation distribution
* Rank vs points analysis
* Top 5 football nation share
* Comparative football analytics

---
